# C++ Basics and Fundamentals

A console program from my C++ coursework that practices core fundamentals: arrays, functions, loops and input validation. It asks for array sizes within a fixed range and keeps prompting until the input is valid.

## Build and run

```bash
g++ basicsAndFundamentals.cpp -o basics
./basics
```

## What I practiced

- Reading and validating user input with `cin`
- Functions with array parameters
- Constants and bounds checking
